# AI Career Assistant

AI Career Assistant is a full-stack web application designed to help job seekers manage their job search, improve their resumes, generate professional cover letters, prepare for interviews, and receive AI-powered career guidance.

## Features

### Authentication

- User Registration
- User Login
- JWT Authentication
- Protected Routes

### Dashboard

- Job Application Statistics
- Recent Applications
- Analytics Overview
- Career Progress Tracking

### Job Tracker

- Add Job Applications
- Edit Applications
- Delete Applications
- Track Application Status
- Search and Filter Jobs
- Application Statistics

### AI Resume Analyzer

- Analyze Resume Text
- Upload and Analyze PDF Resumes
- ATS Score Evaluation
- Resume Strengths & Weaknesses
- Improvement Recommendations

### AI Cover Letter Generator

- Generate Tailored Cover Letters
- Company-Specific Content
- Copy Generated Letters

### AI Interview Questions

- Role-Based Interview Questions
- Technical Questions
- Behavioral Questions
- System Design Questions
- Difficulty Levels

### AI Career Coach

- Personalized Career Advice
- Portfolio Recommendations
- Job Search Guidance
- Interview Preparation Tips

### Subscription Management

- Free Plan
- Pro Plan
- Premium Plan
- Usage Tracking

## Environment Variables

### Frontend (.env)

VITE_API_URL=your_backend_url

### Backend (.env)

PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

OPENAI_API_KEY=your_openai_api_key

## Installation

### Clone Repository

git clone 

cd ai-career-assistant

### Backend Setup

cd server

npm install

npm run dev

### Frontend Setup

cd client

npm install

npm run dev

---

## Deployment

Frontend: Render Static Site

Backend: Render Web Service

Database: MongoDB Atlas
